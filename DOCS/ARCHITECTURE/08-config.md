# 08 — Configuration

`.env` is git-ignored; `.env.example` is tracked. A value is either literal or `admin-manual:<path>#<KEY>`. Read by: **C** client bundle (through `src/config`), **S** server (through `server/core/config.ts`), **B** build scripts. Variables in **C** are public by definition. Req: **R** required for any build, **D** required to deploy or use that feature, **O** optional, **G** generated by the build (not set by hand).

## 8.2 Pointer resolution (`scripts/resolve-env.mjs`)

1. Parse `.env`, line by line. If it is missing, parse `.env.example`.
2. For a value starting `admin-manual:`, split on the last `#`. Join `path` to `ADMIN_MANUAL_PATH`. `.env`-style file: read `KEY=value`. `.json` file: read top-level `KEY`.
3. A missing checkout, file or key fails with the variable's name and the pointer's path. It never prints a resolved value, and the script never echoes any value at any point. Fresh clones with direct values need no checkout.
4. Derive `VITE_WEB_CANONICAL_ORIGIN`, `VITE_WEB_DOMAINS`. Reject `https: false` as the only target with a printed warning (the app then runs per §1.5, row 3).
5. Write the files below with mode 600.

## 8.3 Files the build writes (git-ignored)

| File | Contents | Consumer |
|---|---|---|
| `.generated/.env` | Every `VITE_*` | Vite (`envDir: '.generated'`) |
| `.generated/server.env` | Every S variable | `scripts/deploy-server.mjs`, Node adapter |
| `.generated/build.json` | Every B variable | Build scripts |
| `.generated/secret-values.json` | SHA-256 of every S or B secret value and its length | `scripts/check-no-secrets.mjs` |
| `.generated/tauri.override.json` | `productName`, `identifier`, `version` | `tauri build --config` |

`scripts/check-no-secrets.mjs` scans `dist-web/` and build logs (hashing every token of the matching length) and fails the build on any hit.
